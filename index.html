Installation

1. Copy and paste the link below into Google Chrome. https://focused-edge-coding.github.io/D424CapstoneProject/
2. Click on the “Download Application APK” link to begin downloading the application.
3. Follow the install instructions on screen. Click “Install without scanning” to complete the installation.
4. Open the application.


Login and create an account

1. Enter a test username (Example: testUser01) and password (Example: Testing062026). Click the create account button.
2. The application will bring up the Vacation List page. This page should not contain any information.
3. If the account has been created on that device, type in the credentials used to create the account and click the login button.
4. To log out of the account, navigate to the Vacation List page. Click the 3 dots in the top right corner of the screen, then select the logout option.
